問題

  • 平臺：AtCoder Beginners Selection
  • 題目：ABC081A - Placing Marbles
  • 鏈接：AtCoder 題目說明

輸入是一個由三個 0 或 1 組成的字符串。統計其中有多少個位置是 1。

思路

輸入本身已經是字符串，因此只需掃描其中的字符，並統計等於 '1' 的字符數量。String.count 可以直接表達這個任務。

算法

  • 讀取二進制字符串。
  • 統計等於 '1' 的字符。
  • 輸出計數。

時間複雜度是 O(|s|)，額外空間爲常數。這裏 |s| = 3。

反思

這裏需要使用 Scanf.scanf，因爲它是格式化輸入解析器：它接收一個格式字符串，以及一個消費解析結果的延續函數。相比之下，在打開 Core 後，可以直接使用 printf 進行格式化輸出。

let () = ... 中的模式要求右側表達式產生 unit。因此，對於主要作用是執行輸入輸出效果的程序，它很適合作爲頂層入口。

OCaml 實現

open Core

let () =
  Scanf.scanf "%s" (fun s ->
    printf "%d\n" (String.count s ~f:(Char.equal '1'))
  )
