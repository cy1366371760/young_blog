給定寫在黑板上的若干正整數。只要所有整數都是偶數，就反覆將每個整數除以二。求最多可以執行多少次操作。

思路

對於每個整數，統計它能連續被二整除多少次。整個黑板能執行的次數，取決於其中可除次數最少的元素，因此答案就是這些計數的最小值。

算法

  • 遞歸地將一個數除以 2，直到它變爲奇數，並統計除法次數。
  • 對每個輸入數字應用這個函數。
  • 輸出最小計數。

對於 N 個數字，時間複雜度是 O(N log M)，其中 M 是最大的輸入值。列表變換使用 O(N) 的額外空間。

反思

函數應用的優先級高於除法，因此 count_trailing_zeros (x / 2) 中的括號不可省略。沒有括號時，表達式將表示 (count_trailing_zeros x) / 2。

我最初選擇遞歸，是爲了練習這一思路。如果所選的 OCaml 庫提供尾隨零位操作，也可以用它完成每個數字的計算；本項目使用的 Core.Int API 並未提供 Int.ctz。

帶標籤的參數必須連同標籤一起提供。例如，List.map 使用 ~f: 傳入函數參數，而沒有標籤的參數仍按位置傳遞。

OCaml 實現

open Core

let rec count_trailing_zeros x =
  if x mod 2 = 0 then 1 + count_trailing_zeros (x / 2)  else 0

let () =
  let _n = In_channel.input_line_exn In_channel.stdin |> Int.of_string in
  let ans = In_channel.input_line_exn In_channel.stdin
  |> String.split ~on:' '
  |> List.map ~f:int_of_string
  |> List.map ~f:count_trailing_zeros
  |> List.fold ~init:Int.max_value ~f:(Int.min) in
  printf "%d" ans
