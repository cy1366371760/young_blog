問題

  • 平臺：AtCoder Beginners Selection
  • 題目：ABC083B - Some Sums
  • 鏈接：AtCoder 題目說明

對於從 1 到 N 的每個整數，如果它的十進制各位數字之和位於 A 與 B 之間（包含兩端），就把它加入答案。

思路

N 的約束足夠小，可以檢查每個候選數。把候選數轉換成字符串，將其中的數字字符相加，再把滿足條件的候選數摺疊到最終總和中。

算法

  • 從第一行輸入解析 N、A 和 B。
  • 對 1 .. N 中的每個整數，計算它的十進制各位數字之和。
  • 僅當這個和位於 [A, B] 時，才把該整數加入累加器。

由於需要處理每個候選數的十進制數字，時間複雜度是 O(N log N)。List.range 會把候選數具體化，因此這個實現使用 O(N) 的額外空間。

反思

把數字轉換爲字符串並遍歷字符，表達清晰，也完全足以應對這裏的約束。另一種做法是使用算術方式反覆取末位數字，這樣可以避免臨時字符串分配。

對拆分後的輸入行進行模式匹配很明確，但可能顯得冗長。面對更通用的競賽輸入，值得編寫一個小型的空白標記讀取器。對於簡單的固定格式，Scanf 也很方便。

List.fold (List.range 1 (n + 1)) 避免了帶可變累加器的 for 循環，但中間列表會佔用空間。這裏的代價無關緊要，不過注意到這種權衡是一個好習慣。

function 是 fun x -> match x with ... 的簡寫：其中的 x 是一個新的函數參數，並不是外圍作用域中的已有變量。

OCaml 實現

open Core

let count_sum_digits x = x
 |> Int.to_string
 |> String.fold ~init:0 ~f:(fun acc c -> acc + Char.to_int c - Char.to_int '0')

let () =
  let n, a, b = In_channel.input_line_exn In_channel.stdin
  |> String.split ~on:' '
  |> function
  | [n; a; b] -> Int.of_string n, Int.of_string a, Int.of_string b
  | _ -> failwith "gg"
  in
  let ans = List.fold (List.range 1 (n+1)) ~init:0 ~f:(fun acc x ->
    let digit_sum = count_sum_digits x in
    if a <= digit_sum && digit_sum <= b then acc + x
    else acc) in
  printf "%d\n" ans
