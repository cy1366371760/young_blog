問題

  • 平臺：AtCoder Beginners Selection
  • 題目：ABC085B - Kagami Mochi
  • 鏈接：AtCoder 題目說明

給定 N 個直徑爲整數的圓形年糕。要求堆出盡可能高的一疊，並且每個年糕的直徑都必須嚴格小於它下面的年糕。求最多可以堆多少層。

思路

每一種不同的直徑都可以在合法堆疊中出現一次，而相同直徑的年糕不能同時使用。因此，答案就是不同直徑的數量。

這個解法先使用遞歸快速排序對列表排序，然後掃描排序結果，統計相鄰值發生變化的次數。

算法

  • 讀取 N 個直徑。
  • 使用快速排序對它們排序。
  • 遍歷排序後的列表，每個新值只計數一次。
  • 輸出計數。

使用隨機樞軸時，快速排序的期望時間複雜度是 O(N log N)。計數過程是 O(N)，基於列表的實現還會爲排序和分區後的列表使用額外內存。

反思

對於整數，Int.compare 和 Int.equal 可以明確表達預期的類型專用比較。像 < 和 = 這樣的多態比較運算符對整數也正確，但養成使用 Core 輔助函數的習慣會更清晰。當前的 count_unique 實現仍使用 =；在那裏改用 Int.equal 會讓風格保持一致。

快速排序可以通過匹配 pivot :: rest，再使用一次 List.fold 同時生成小於、等於和大於樞軸的列表，從而更高效地完成分區。這可以替代當前的三次 List.filter 遍歷。它並不是 List 庫的替代方案：模式匹配負責暴露頭部與尾部，List.fold 負責完成單次遍歷。

在不同值計數的遞歸中，x :: ((y :: _) as tail) 這樣的別名模式可以直接複用 tail，而不用在每次比較後重新構造 y :: rem。配合顯式整數比較，可以寫成緊湊的 if Int.equal x y then count_unique tail else 1 + count_unique tail。

這道題的輸入規模最多爲 100，因此當前實現已經足夠快。熟悉底層操作後，List.dedup_and_sort ~compare:Int.compare 會是最直接的 Core 庫解法。

OCaml 實現

open Core

let rec qsort a =
  let n = List.length a in
  if n <= 1 then a else
    let pos = Random.int n in
    let bas = List.nth_exn a pos in
    qsort (List.filter a ~f:(fun x -> Int.compare x bas < 0)) @
    (List.filter a ~f:(fun x -> Int.equal x bas)) @
    qsort (List.filter a ~f:(fun x -> Int.compare x bas > 0))

let () =
  let n = Scanf.scanf " %d" (fun x -> x) in
  let d = List.init n ~f:(fun _ -> Scanf.scanf " %d" (fun x -> x)) in
  let sorted_d = qsort d in
  let rec count_unique = function
  | [] -> 0
  | [_] -> 1
  | x :: y :: rem -> if x = y then count_unique (y :: rem) else 1 + count_unique (y :: rem) in
  let res = count_unique sorted_d in
  printf "%d\n" res
