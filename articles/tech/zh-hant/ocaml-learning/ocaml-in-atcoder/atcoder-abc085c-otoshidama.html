問題

  • 平臺：AtCoder Beginners Selection
  • 題目：ABC085C - Otoshidama
  • 鏈接：AtCoder 題目說明

給定總價值爲 Y 日元的 N 張紙幣，求一種由 10000、5000 和 1000 日元紙幣組成的可能數量。如果不存在這樣的組合，輸出 -1 -1 -1。

思路

先選定 10000 日元紙幣的數量。做出這個選擇後，只剩下 5000 與 1000 日元紙幣的數量和值。這兩個未知數由兩個方程決定，因此不需要第二層嵌套循環。

設有 a 張 5000 日元紙幣和 b 張 1000 日元紙幣，剩餘紙幣數量爲 num，剩餘金額爲 total：

5000a + 1000b = total
a + b = num

用第一個方程減去 1000 * (a + b)，得到：

4000a = total - 1000 * num

右側必須非負並且能被 4000 整除。隨後，b 就是 num - a。

算法

  • 從 0 到 N 枚舉 n10000。
  • 剩餘紙幣數量爲 N - n10000，並從 Y 中減去已經選定紙幣的價值。
  • 求解剩餘的二元方程，並驗證兩個數量都非負。
  • 返回第一個有效三元組；如果不存在，則返回 -1 -1 -1。

時間複雜度是 O(N)。better.ml 實現使用 Sequence，因此會惰性地產生候選值，而不是分配一個包含 N + 1 個值的列表。

反思

Sequence.range 很適合這裏，因爲候選值會逐個消費，而且找到第一個答案後搜索就會停止。相比之下，List.init 會在 List.find_map 開始搜索之前構建完整的候選列表。兩者的漸近時間複雜度相同，但序列版本使用的中間空間更少。

solve_remaining ~num ~total 中的標籤參數，讓含義不同的兩個整數輸入更不容易被意外交換。調用處讀起來也更像它所表達的方程。

find_map 不只是找出匹配的輸入：它會返回映射函數產生的第一個非 None 值。因此，可以自然地把求出的 n10000、n5000 和 n1000 數量作爲最終三元組保存在一起。

原始 OCaml 實現

open Core

(* 5000a + 1000b = tot, a + b = num *)
let solve num tot =
  let a_4000 = tot - num * 1000 in
  if a_4000 < 0 || a_4000 mod 4000 <> 0 then None
  else let a = a_4000 / 4000 in
  let b = num - a in
  if a < 0 || b < 0 then None
  else Some(a, b)

let () =
  let n,y = Scanf.scanf " %d %d" (fun x y -> (x, y)) in
  List.init (n + 1) ~f:(fun x -> x)
  |> List.find_map ~f:(fun x -> solve (n - x) (y - 10000 * x))
  |> function
  | None -> printf "-1 -1 -1\n"
  | Some(a,b) -> printf "%d %d %d\n" (n-a-b) a b

改進後的 OCaml 實現

open Core

let solve_remaining ~num ~total =
  let excess = total - (num * 1000) in
  if excess < 0 || excess mod 4000 <> 0 then
    None
  else
    let n5000 = excess / 4000 in
    let n1000 = num - n5000 in
    if n5000 <= num then
      Some (n5000, n1000)
    else
      None

let () =
  let n, y = Scanf.scanf " %d %d" (fun n y -> n, y) in

  Sequence.range 0 (n + 1)
  |> Sequence.find_map ~f:(fun n10000 ->
    solve_remaining
      ~num:(n - n10000)
      ~total:(y - (10000 * n10000))
    |> Option.map ~f:(fun (n5000, n1000) ->
      n10000, n5000, n1000))
  |> function
  | Some (a, b, c) ->
      printf "%d %d %d\n" a b c
  | None ->
      printf "-1 -1 -1\n"
