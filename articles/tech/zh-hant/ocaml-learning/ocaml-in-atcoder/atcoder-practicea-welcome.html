給定三個整數和一個字符串，輸出整數之和，後面再輸出該字符串。

思路

這是一道輸入輸出練習。唯一需要稍加註意的是，輸入分佈在三行中，而 Scanf.scanf 可以跨越行邊界讀取由空白分隔的標記。

算法

  • 讀取 a、b、c 和 s。
  • 計算 a + b + c。
  • 輸出總和與 s，中間以一個空格分隔。

時間複雜度和額外空間複雜度都是常數。

反思

這是我的第一個示例。它適合用來了解 OCaml 競賽程序的完整流程：讀取標準輸入、計算結果，再按要求的格式輸出。

OCaml 實現

open Core

let () =
  Scanf.scanf "%d %d %d %s" (fun a b c s ->
    let sum = a + b + c in
    printf "%d %s\n" sum s)
